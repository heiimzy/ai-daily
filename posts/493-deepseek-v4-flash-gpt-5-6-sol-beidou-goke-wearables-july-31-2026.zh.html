DeepSeek-V4-Flash 正式版 API 上线公测：Agent 能力大幅增强

今天（7月31日）下午，DeepSeek 通过 API 文档发布日志宣布，DeepSeek-V4-Flash 正式版 API 上线公测。根据官方介绍，V4-Flash 的 Agent 能力大幅增强，在多项基准测试中远超 V4-Pro-Preview：Terminal Bench 2.1 得分 82.7、NL2Repo 54.2、Cybergym 76.7、DeepSWE 54.4、Toolathlon verified 70.3、Agent Last Exam 25.2、Automation Bench（Public）25.1、DSBench-FullStack 68.7、DSBench-Hard 59.6。

据悉，正式版 V4-Flash 原生支持 Responses API 格式，并针对 Codex 做了适配优化。DeepSeek-V4-Flash-0731 的模型结构、尺寸与 V4-Flash-preview 保持一致，仅重新进行了后训练。官方还表示，本次仅升级了 V4-Flash 的 API 接口，DeepSeek-V4-Pro API 及 APP/WEB 端模型未做更改，V4-Pro 正式版将会「尽快」发布。

OpenAI 修复框架缺陷：GPT-5.6 Sol 在 ARC-AGI-3 提分 188%

OpenAI 今天发布公告，宣布通过改进测试框架，让 GPT-5.6 Sol 模型在 ARC-AGI-3 基准测试中的得分提高 188%。ARC-AGI-3 由 ARC Prize 团队推出，是目前公认衡量 AI 通用智能（AGI）最严苛的交互式推理评测基准——它不采用传统「做题」模式，而是把 AI 放进完全陌生的「游戏环境」中，评估其实时探索、学习与自适应能力。

在未优化前，GPT-5.6 Sol 在 ARC-AGI-3 的得分为 7.8%（GPT-5.5 仅为 0.4%）。OpenAI 复盘发现官方框架存在两个影响表现的问题：一是每次游戏动作后私有推理被丢弃，模型每执行一次动作都要重新理解游戏；二是滚动截断窗口会让较早动作从上下文中消失。针对这两点，OpenAI 提出「推理保留」（inference preservation）和「上下文压缩」（context compression）两个方案。启用后，GPT-5.6 Sol 得分从 13.3% 升至 38.3%，增长 188.42%，同时 Token 输出量降低至原来的六分之一。

北斗卫星导航系统全面完成在轨升级：在轨卫星达 50 颗

据中国卫星导航系统管理办公室 31 日消息，北斗卫星导航系统已全面完成在轨升级。此次升级于今年 3 月正式启动，采取「分批实施、逐星验证、动态切换」的策略，聚焦提升星间链路传输效率、优化复杂环境下信号捕获能力及增强系统抗干扰性等核心方向，使北斗在全球导航卫星系统中率先具备大规模在轨软件定义与持续演进的能力。

目前，我国北斗系统在轨运行卫星数量已达 50 颗，空间信号精度优于 2 米，全球定位精度优于 10 米；通过精密单点定位服务，可实现水平精度优于 0.3 米、垂直精度优于 0.6 米的高精度定位。官方表示，后续将在确保稳定运行的基础上丰富发展新的导航技术手段，努力实现 2035 年前建设完善更加泛在、更加融合、更加智能的综合时空体系的目标。

格科发布 5000 万像素 CMOS 传感器 GC50B5：单帧 HDR + 4K 120fps

格科今日宣布推出全场景高动态 5000 万像素 CMOS 图像传感器 GC50B5。该产品采用 1/1.56 英寸光学尺寸、1.0μm 大像素，搭载双转换增益（DCG）单帧高动态技术，支持 100% 全像素相位检测自动对焦（4-Cell PDAF）、2 倍传感器内变焦、NOMF 闪拍以及 4K 120fps DAG HDR 视频、4K 60fps DCG HDR 视频输出。

GC50B5 的核心优势在于 DCG HDR 单帧高动态技术：在像素信号由电荷转换为电压时，通过切换浮动扩散节点电容，以高、低两种转换增益分别读取同一次曝光信号，融合后生成高动态范围图像，在高光比环境中保留高光细节的同时降低暗部噪声，并避免多帧融合导致的运动伪影。该产品基于格科 GalaxyCell 2.0 工艺平台开发，现已接受送样。据公司公告，截至 2026 年 7 月 24 日，格科 5000 万像素图像传感器产品累计出货已超 1.2 亿颗。

昆仑万维 Skywork AI 硬件家族登场：17.4 克 AI 挂件 + AI 戒指 TriRing

昆仑万维今日宣布，Skywork 整套智能硬件家族即将陆续登场，AI 挂件 Recall 与 AI 戒指 TriRing 将于近期陆续上线。AI 挂件 Skywork Recall 重仅 17.4 克，内置 VAD 语音检测——有人说话才开始录，安静下来自动休眠，官方称可以全天佩戴、连续戴好几天。

AI 戒指 Skywork TriRing 重约 4 至 6 克，采用陶瓷与钛合金双拼设计，搭载行业首个双麦克风降噪算法，「记一件事只要双击一下，剩下的判断就交给 Agent」。此外，Skywork Note 的升级版 Skywork Mate 即将发售，搭载 6nm AI 音频芯片，用神经网络滤掉 500 多种环境噪音，主打「连上 Wi-Fi，录完即走」。
