DeepSeek V4-Flash Production API Enters Public Beta with Big Agent Gains

This afternoon, DeepSeek announced via its API documentation changelog that the production DeepSeek-V4-Flash API has entered public beta. According to the company, V4-Flash's agent capabilities are significantly stronger, far surpassing V4-Pro-Preview across benchmarks: Terminal Bench 2.1 at 82.7, NL2Repo 54.2, Cybergym 76.7, DeepSWE 54.4, Toolathlon verified 70.3, Agent Last Exam 25.2, Automation Bench (Public) 25.1, DSBench-FullStack 68.7, and DSBench-Hard 59.6.

The production V4-Flash natively supports the Responses API format and is optimized for Codex. The DeepSeek-V4-Flash-0731 model keeps the same structure and size as the V4-Flash-preview, with only post-training changes. DeepSeek noted that this update touches only the V4-Flash API — the V4-Pro API and APP/WEB models are unchanged, and the production V4-Pro release will arrive "as soon as possible."

OpenAI Fixes Harness Flaws: GPT-5.6 Sol Scores 188% Higher on ARC-AGI-3

OpenAI announced today that it improved the GPT-5.6 Sol model's score on the ARC-AGI-3 benchmark by 188% through framework fixes. ARC-AGI-3, created by the ARC Prize team, is widely considered the most demanding interactive reasoning benchmark for measuring AI general intelligence — instead of traditional question-answering, it drops AI into completely unfamiliar "game environments" to assess real-time exploration, learning, and adaptation.

Before optimization, GPT-5.6 Sol scored 7.8% on ARC-AGI-3 (GPT-5.5 managed just 0.4%). OpenAI's review found two flaws in the official harness: private reasoning was discarded after every game action, forcing the model to re-understand the game each turn; and a rolling truncation window dropped earlier actions from context. OpenAI introduced two fixes — inference preservation and context compression. With both enabled, GPT-5.6 Sol's score rose from 13.3% to 38.3%, a 188.42% improvement, while token output dropped to one-sixth of the original.

BeiDou Navigation System Completes Full On-Orbit Upgrade: 50 Satellites in Service

According to the China Satellite Navigation Office, the BeiDou Navigation Satellite System has fully completed its on-orbit upgrade. The upgrade, launched in March this year, used a "batch-by-batch implementation, satellite-by-satellite verification, and dynamic switching" strategy, focusing on improving inter-satellite link transmission efficiency, signal acquisition in complex environments, and anti-jamming capability. BeiDou is now the first GNSS constellation with large-scale on-orbit software-defined and continuous evolution capabilities.

BeiDou currently has 50 satellites in orbit, with space signal accuracy better than 2 meters and global positioning accuracy better than 10 meters. Through precise point positioning services, it achieves horizontal accuracy better than 0.3 meters and vertical accuracy better than 0.6 meters. The office said it will continue enriching navigation technology while ensuring stable operation, targeting a more ubiquitous, integrated and intelligent spatiotemporal system by 2035.

Goke Launches 50MP CMOS Sensor GC50B5: Single-Frame HDR and 4K 120fps

Goke today announced the GC50B5, a full-scene high-dynamic-range 50-megapixel CMOS image sensor. It features a 1/1.56-inch optical format with 1.0μm large pixels, dual conversion gain (DCG) single-frame HDR, 100% full-pixel phase detection autofocus (4-Cell PDAF), 2x in-sensor zoom, NOMF flash capture, and 4K 120fps DAG HDR or 4K 60fps DCG HDR video output.

The GC50B5's core strength is DCG single-frame HDR: as pixel signals convert from charge to voltage, the sensor switches the floating diffusion node capacitance and reads the same exposure at high and low conversion gains, fusing them into a high-dynamic-range image. This preserves highlight detail in high-contrast scenes while reducing shadow noise, avoiding the motion artifacts of multi-frame fusion. Built on Goke's GalaxyCell 2.0 process platform, the sensor is now sampling. As of July 24, 2026, Goke's cumulative shipments of 50MP image sensors had surpassed 120 million units.

Kunlun's Skywork AI Wearables: 17.4g AI Pendant and the TriRing AI Ring

Kunlun Tech announced today that its full Skywork AI wearables family is arriving soon, with the Recall AI pendant and the TriRing AI ring launching in the near term. The Recall pendant weighs just 17.4 grams and features built-in VAD voice detection — it only starts recording when someone speaks and automatically sleeps when quiet. The company says it can be worn all day, even for several days straight.

The TriRing AI ring weighs about 4 to 6 grams, pairs ceramic with titanium, and packs the industry's first dual-microphone noise reduction algorithm — "double-tap to record an event, and let the Agent handle the rest." In addition, the upgraded Skywork Mate voice recorder is coming soon with a 6nm AI audio chip that uses neural networks to filter out more than 500 environmental noises, billed as "connect to Wi-Fi, record and go."
