⚡ July 29 Tech Triple: Nvidia Launches Nemotron 3 Open-Source AI Models with 4x Throughput, Tencent Open-Sources Hunyuan World Model 1.5, OpenAI Debuts GPT-5.6 Trio and ChatGPT Work

1. Nvidia Nemotron 3: Open-Source MoE Family with 4x Throughput

On July 29, Nvidia officially unveiled the Nemotron 3 open-source AI model series, featuring three variants — Nano, Super, and Ultra — which it claims is the "most efficient open-source model family with the best accuracy for building AI agent applications." This marks another major push by Nvidia into the open-source AI space, positioning itself directly against Meta's Llama and Mistral.

Three Tiers Covering Every Use Case

The Nemotron 3 series uses a novel Mixture of Latent Experts (MoE) architecture across three variants:

  • Nemotron 3 Nano: A compact 30-billion-parameter model with up to 3B active parameters per token, optimized for software debugging, content summarization, AI assistant workflows, and low-cost information retrieval. Achieves up to 4x token processing throughput over Nemotron 2 Nano with 60% fewer inference tokens, supporting a 100K-token context window.
  • Nemotron 3 Super: A high-accuracy reasoning model with approximately 100B parameters and up to 10B active parameters per token, targeting multi-agent applications.
  • Nemotron 3 Ultra: A large-scale reasoning engine with approximately 500B parameters and up to 50B active parameters per token, designed for the most complex AI workloads.

Enterprise Ecosystem Adoption

Nvidia announced 12 early adopters including EY, Cisco, Oracle Cloud Infrastructure, Palantir, Perplexity, ServiceNow, Siemens, Synopsys, Zoom, Accenture, Cadence, and Cursor — all integrating Nemotron 3 into their AI workflows across manufacturing, cybersecurity, software development, media, and communications.

Nemotron 3 Nano is available today on Hugging Face, with Super and Ultra expected in the second half of 2026. Nvidia emphasized that open Nemotron 3 enables startups to build and iterate AI agents faster, accelerating the innovation cycle from prototype to enterprise deployment.

"As organizations move from single-model chatbots to collaborative multi-agent AI systems, developers face challenges including communication overhead, context drift, and high inference costs. Nemotron 3 directly addresses these challenges, providing the expressiveness and openness needed to build specialized agentic AI." — Nvidia official statement

2. Tencent Hunyuan World Model 1.5 Open-Sourced: Industry's First Real-Time World Model Framework

On the morning of July 29, Tencent's Hunyuan team officially released World Model 1.5 (Tencent HY WorldPlay), open-sourcing what it calls the industry's most systematic and comprehensive real-time world model training framework, covering data, training, and streaming inference deployment across the full pipeline.

Three Core Innovations

At the heart of World Model 1.5 is WorldPlay, an autoregressive diffusion model trained on Next-Frames-Prediction vision autoregressive tasks, achieving real-time interactive world modeling with long-range geometric consistency:

  • Real-time interactive generation: Using a novel Context Forcing distillation scheme and streaming inference optimization, the model generates 720P HD video at 24 FPS.
  • Long-range 3D consistency: Through Reconstituted Memory mechanism, the model supports minute-level geometric consistency generation for building high-quality 3D space simulators.
  • Diverse interaction experiences: Supports various game styles and real-world scenes, first and third-person perspectives, real-time text-triggered events, and video continuation.

Breakthrough: Spatial Memory

World Model 1.5 brings entirely new possibilities to world modeling. Users can freely explore generated worlds — when leaving an area and returning, the model "remembers" the three-dimensional structure, presenting a consistent scene. This spatial memory capability marks a major breakthrough in 3D world understanding. The model also supports exporting interactive 3D scenes as reusable 3D point clouds.

The model relies on three core innovations: dual-branch action representation for precise control, contextual memory reconstruction for geometric consistency, and context-aligned distillation for enhanced visual quality in long video generation. The team also built a 3D-reward-based reinforcement learning post-training framework and automated 3D scene rendering pipeline for high-quality training data generation.

The model is fully open-sourced on GitHub, Hugging Face, and Tencent Cloud platform, complete with a technical report and online demo.

3. OpenAI Launches GPT-5.6 Trio: ChatGPT Work Merges with Codex

On July 29, OpenAI officially released the GPT-5.6 series to global users, alongside ChatGPT Work — an AI agent workspace that merges ChatGPT with the Codex programming tool, marking the transition of AI office tools from "assisted conversation" to "autonomous delivery."

Three-Tier Strategy Covers Full Spectrum

The GPT-5.6 series includes three tiers:

  • Sol (Flagship): Specialized in hardcore coding, research, and cybersecurity, scoring 80 on the Artificial Analysis Coding Agent Index with max reasoning enabled — a new SOTA. API pricing: $5/M input tokens, $30/M output tokens.
  • Terra (Balanced): For general development tasks at $2.5/M input, $15/M output.
  • Luna (Lightweight): For daily lightweight tasks at $1/M input, $6/M output.

GPT-5.6 introduces max and ultra reasoning modes, with ultra mode orchestrating 4 parallel agents by default, expandable to 16. Plus membership remains at $20/month.

ChatGPT Work: Where Conversation Meets Code

ChatGPT Work is OpenAI's direct response to Anthropic's Claude Cowork. Powered by GPT-5.6, it handles information gathering, data analysis, document writing, presentation creation, and website generation. It supports connections to Slack, Gmail, cloud storage, and enterprise databases for end-to-end workflow integration.

GPT-5.6 is available across ChatGPT, Codex, and the OpenAI API. On the same day, ChatGPT and Codex completed their merger, marking a major product integration for OpenAI. Users can access it at openai.com/chatgpt.

Industry Implications

Three major companies releasing heavyweight AI models on the same day signals that AI competition is evolving from single-model capabilities to a "model + platform + ecosystem" paradigm. Nvidia strengthens its AI infrastructure position with open-source MoE models, Tencent pioneers spatial intelligence with world models, and OpenAI pushes the AI office paradigm shift with GPT-5.6 + Codex integration. Together, these events point to one overarching trend: AI is moving from "what it can do" to "what it can deliver."
